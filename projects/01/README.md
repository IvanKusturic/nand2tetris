# Project 01 — Boolean Logic

HDL implementations of basic logic gates, built from the Nand primitive, plus
their 16-bit and multi-way variants.

## Chips

- `Not`, `And`, `Or`, `Xor` — basic gates
- `Mux`, `DMux` — multiplexor and demultiplexor
- `Not16`, `And16`, `Or16` — 16-bit variants
- `Mux16`, `Mux4Way16`, `Mux8Way16` — wider muxes
- `Or8Way` — 8-way Or
- `DMux4Way`, `DMux8Way` — wider demuxes
