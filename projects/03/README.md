# Project 03 — Sequential Logic

HDL implementations of the clocked chips: a 1-bit register, 16-bit register,
RAM units of varying sizes, and a program counter.

## Chips

- `Bit` — 1-bit register
- `Register` — 16-bit register
- `RAM8`, `RAM64`, `RAM512`, `RAM4K`, `RAM16K` — memory units
- `PC` — program counter
