# Nand2Tetris

Solutions to the Nand2Tetris course (also known as *Build a Modern Computer
from First Principles* / *The Elements of Computing Systems* by Noam Nisan and
Shimon Schocken), taken via Coursera.

All chips and programs were implemented and tested using the
[online IDE](https://nand2tetris.github.io/web-ide/chip/).

## Projects

- [`projects/01`](projects/01) — Boolean Logic
- [`projects/02`](projects/02) — Boolean Arithmetic
- [`projects/03`](projects/03) — Sequential Logic
- [`projects/04`](projects/04) — Machine Language
- [`projects/05`](projects/05) — Computer Architecture
- [`projects/06`](projects/06) — Assembler
- [`projects/07`](projects/07) — VM Translator I: Stack Arithmetic
